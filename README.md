# Express.js

A collection of Express.js examples and practice code created while learning backend development with Node.js.

## About

This repository explores how Express.js simplifies building web servers and APIs using Node.js.
The repository contains examples and experiments covering different concepts, with individual folders serving as separate learning exercises.

## Topics Explored

- **Express.js Fundamentals** — application setup and server creation
- **Routing** — handling HTTP methods and defining endpoints
- **Middleware** — request processing and middleware chaining
- **Request and Response Handling** — working with HTTP requests and responses
- **REST APIs** — building backend API endpoints
- **MVC Architecture** — separating application logic into Models, Views, and Controllers
- **Server-Side Rendering (SSR)** — generating HTML on the server and delivering rendered pages to the browser
- **Template Engines** — dynamically rendering HTML pages using server-side templates
- **Blog Application** — applying MVC and SSR concepts in a blog-oriented web application
- **Route Parameters and Query Strings** — extracting data from request URLs
- **Static Files** — serving static assets
- **Error Handling** — handling errors during request processing

*The topics listed are representative of Express.js learning; the exact coverage depends on the examples in this repository.*

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
  nodemon utility
- A code editor such as Visual Studio Code

### Clone the Repository

```bash
git clone https://github.com/naba93980/expressjs.git
cd expressjs
```

Navigate to the relevant example directory, install its dependencies if a `package.json` is present, and run the appropriate JavaScript entry file or npm script.
